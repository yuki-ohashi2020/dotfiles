# 📱 03\_アプリの管理

CLIツールやGUIアプリのインストールや更新、削除のルール

## 🛠️ 使用ツール

- Homebrew

### Homebrew

Macでのパッケージ管理の事実上の標準。  
開発環境やツール管理の自動化・再現性を高めるために採用。

- パスの統一化
  - CLIツールやGUIアプリを一貫性のあるパスに配置できる
  - brewのPATH設定を行えばツールやアプリの呼び出しが楽になる
- 依存関係の自動解決
  - 必要なライブラリや補助ツールを自動でインストールしてくれる
  - 手動ビルドやバージョン衝突のリスクを減らす
