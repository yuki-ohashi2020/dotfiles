# 💻 02\_ハードウェア要件

## 🧑‍💻 必須要件

- **OS:** macOS（Sonoma以降推奨）
- **チップ:** Apple Silicon (M1以降)
- **メモリ:** 32GB以上推奨

### 📝 開発・テスト環境

この設定は以下の環境で開発・テストされている:

- **チップ:** Apple M4 Pro
- **メモリ:** 48 GB

## 🛠️ 対象デバイス

このdotfilesは以下のデバイス構成を前提としている:

### ⌨️ キーボード

- Caps Lockつき
- 左右の装飾キーあり（Command, Option, Control など）
- テンキーは不要

### 🖲️ マウス

- トラックボール付き
- ボタンが 2 個以上

### 🖥️ ディスプレイ

- メインモニター：24インチ以上
- 拡張ディスプレイ：15インチ縦型
