# 📋 01\_概要

Macでの日常作業と開発を効率化するための統合環境設定である。

## 🎯 dotfilesの管理対象

- **ツール管理**: アプリとCLIツールの統一管理
- **操作環境(UI)**: キーボード、マウス、ウィンドウ操作の最適化
- **表示環境**: ディレクトリ構成、ミニマルUI、通知設定
- **ワークフロー**: 日常・開発タスクの自動化スクリプト

## ✨ 設計思想

- **ワーキングメモリを消費しない**: 操作の一貫性、情報の最小化
- **本質的な作業に集中できる**: 自動化、中断の排除
- **長く使い続けられる**: 保守性、カスタマイズ性

## 🚫 非スコープ

- Windows・Linux環境への対応
- チーム共有設定（個人環境に最適化）
