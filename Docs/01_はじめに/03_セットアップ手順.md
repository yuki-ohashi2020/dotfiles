# 🚀 03\_セットアップ手順

Macの買い替え時や環境構築を最初からやり直す時に行う手順

## 🛠️ 使用ツール

- Makefile
- Shell Script(bash)

### 🟢 Makefileの選定理由

- **制御性**: 複数のShell Scriptを順序通りに実行可能
- **柔軟性**: 全体セットアップや部分的セットアップの切り替えが可能

```bash
# 全体セットアップ
make setup

# 部分セットアップ(例)
make setup-network
make setup-finder
```

### 🟢 Shell Script(bash)の選定理由

- **互換性**: zsh環境が整っていない初期Macでも確実に実行可能
- **標準搭載**: bashはmacOS標準で利用可能なため、追加インストール不要
- **保守性**: Makefileから呼び出すことで、処理の分離と再利用が容易

## 📑 インストール手順

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/yuki-ohashi2020/dotfiles/main/install.sh)"

cd ~/.local/share/chezmoi
make setup
```
